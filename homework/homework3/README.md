# 習題 3：SubCal Lite (v1.0) - 智慧訂閱管理系統初版

## 一、專案發想與價值
現代人同時訂閱 Netflix、Spotify、ChatGPT Plus、雲端空間等多種數位服務，卻常因為扣款週期不同（月繳與年繳混雜）而難以估算每月真實固定開銷。因此本專案設計了 **SubCal Lite (v1.0)**，協助使用者快速登錄訂閱項目並自動換算月均與年度總支出。

## 二、本版 (v1.0) 完成功能
1. **核心訂閱 CRUD**：支援新增與刪除訂閱項目（記錄名稱、價格、週期、分類與下次扣款日）。
2. **月繳與年繳自動攤提試算**：自動將年繳金額除以 12 換算為每月等值支出，即時更新上方三大財務指標卡。
3. **資料持久化儲存**：使用瀏覽器 `LocalStorage` 保存資料，重新整理頁面不遺失。

## 三、未來擴充計畫（於第八週 Homework 8 實作完成）
本初版完成核心概念驗證（PoC）後，於後續週次進一步重構升級為 React + TypeScript 完整版 SaaS 系統，擴充互動式扣款月曆、免費試用到期預警、瀏覽器桌面推播與圓餅圖財務報表。

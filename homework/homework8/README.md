# SubCal - 智慧訂閱管理系統 (Subscription Management & Calendar System)

## 一、專案目的与背景
現在有越來越多數位服務採用訂閱制（Subscription Model），例如 Netflix、Spotify、YouTube Premium、遊戲會員（PC Game Pass）、雲端空間（Google One）及各類 AI 工具（ChatGPT Plus、Claude Pro）等。使用者在同時訂閱多項服務後，常會忘記自己訂閱了哪些項目、何時會被自動扣款、免費試用何時到期，以及每個月與全年的累積花費究竟有多少。

**SubCal（智慧訂閱管理系統）** 旨在提供一個現代化、直覺且可實際操作的 SaaS 風格網頁應用程式，協助使用者集中管理所有定期支出，透過視覺化儀表板、互動式月曆、智慧到期提醒與財務攤提統計，全面掌握個人定期定額支出狀況。

---

## 二、技術架構 (Tech Stack)
本專案採用純前端現代化架構開發，無須依賴外部後端伺服器即可獨立運作並持久化保存資料：

- **前端框架**：React 18 + TypeScript
- **建置工具**：Vite
- **樣式設計**：Tailwind CSS（現代化 SaaS 響應式介面設計，支援桌面與行動裝置）
- **圖示庫**：Lucide React (`lucide-react`)
- **資料儲存**：瀏覽器原生 `LocalStorage`（具備 JSON 備份匯出與匯入機制）
- **通知系統**：站內智慧提醒演算法 + 瀏覽器原生 `Notification API`

## 三、核心功能模組

### 1. 首頁儀表板 (Dashboard)
- **關鍵財務指標卡片**：即時統計「目前啟用訂閱數」、「每月預估總支出」、「全年預估總支出」與「免費試用追蹤數」。
- **近期重要提醒橫幅**：自動置頂顯示 7 天內即將扣款與免費試用即將期滿的警示。
- **最近即將扣款清單**：依下次扣款日期由近到遠排序，快速掌握近期現金流。
- **近期免費試用追蹤**：醒目顯示試用剩餘天數與結束日期，避免忘記取消而被收取正價費用。
- **當月訂閱支出結構圖**：即時呈現各分類每月等值花費佔比。

### 2. 訂閱管理 (Subscription Management)
- **完整 CRUD 功能**：支援新增、編輯、刪除訂閱項目，以及一鍵切換「使用中 / 已取消」狀態。
- **詳細欄位紀錄**：包含服務名稱、價格、幣別（預設 TWD，支援 USD/JPY）、付款週期（月繳/年繳）、下次扣款日、7 大分類（娛樂、音樂、遊戲、AI 工具、雲端服務、工作、其他）、免費試用標記與試用結束日、備註等。
- **搜尋、篩選與排序**：支援關鍵字即時搜尋、依分類與狀態篩選，以及依「下次扣款日」、「每月等值費用高低」、「名稱」排序。
- **歷史紀錄保留**：已取消的訂閱不會被直接抹除，仍保留於清單中供日後對帳查閱，且自動排除於每月/全年支出統計之外。
- **內建展示資料**：首次開啟網站時自動載入 8 筆精選範例資料，方便立即體驗完整功能。

### 3. 訂閱日曆 (Subscription Calendar)
- **互動式月曆介面**：支援切換上一個月、下一個月與快速回到今天。
- **精準週期推算**：自動根據月繳與年繳規則，在對應日期格內顯示扣款服務標籤，並依分類呈現專屬配色。
- **當月與當日明細**：自動加總當月預計實際扣款總額；點擊任一日期可在右側面板檢視當天的所有扣款項目與單日小計。

### 4. 智慧提醒中心 (Notification Center)
- **多階段自動預警**：
  - 免費試用結束前提醒 / 當日到期緊急警示。
  - 扣款前 3 天與當日緊急提醒。
  - 扣款前 7 天預告提醒。
- **瀏覽器桌面推播**：整合瀏覽器原生 `Notification API`，使用者授權後可於網站開啟時發送系統桌面通知。

### 5. 支出統計 (Analytics)
- **月繳與年繳智慧攤提**：正確處理不同週期的成本換算（例如：年繳 1,200 元自動換算為每月等值支出 100 元；月繳 100 元則全年預估為 1,200 元）。
- **各分類支出比例圓餅圖**：視覺化呈現娛樂、AI 工具、雲端服務等分類的花費結構。
- **花費最高服務排行榜**：依每月等值費用由高至低排列，協助使用者檢視主要支出來源並評估是否降級或取消。
- **未來 12 個月實際扣款變化長條圖**：結合月繳固定支出與年繳到期月份，預先掌握未來一年哪幾個月會有帳單峰值。

### 6. 系統設定與資料備份 (Settings)
- **JSON 備份匯出與匯入**：可將所有訂閱紀錄匯出為 `.json` 檔案保存，或匯入既有備份。
- **範例資料重置與清空**：支援一鍵還原預設範例資料，或清空所有資料從頭建立個人清單。

## 五、如何安裝與啟動網站

### 1. 安裝相依套件

在專案目錄（`homework8`）下開啟終端機，執行：

```bash
npm install --legacy-peer-deps
```

### 2. 啟動開發伺服器

安裝完成後，執行：

```bash
npm run dev
```

啟動成功後，在瀏覽器開啟終端機顯示的本地網址（預設為 http://localhost:5173/），即可開始操作網站。

### 3. 正式環境打包建置

若要確認專案能否正常建置，執行：

```bash
npm run build
```

## 六、目前限制與未來擴充方向

### 1. 背景推播通知（Web Push / Email）

目前第一版採用純前端架構與瀏覽器 Notification API，提醒功能主要在網站開啟時運作，無法保證關閉網頁後仍能自動發送通知。

未來可以串接後端排程（Cron Job）以及 Email 或其他通知服務，實現網站關閉後仍能接收的背景提醒。

### 2. 多幣別即時匯率換算

目前系統支援選擇 TWD、USD、JPY 等幣別，並可顯示各項訂閱的金額。

未來可以串接即時匯率 API，自動將不同幣別的訂閱費用換算為新台幣，方便統一計算每月及每年的總支出。

### 3. 跨裝置雲端同步

目前資料儲存在使用者本機瀏覽器的 LocalStorage 中，資料不會自動同步至其他裝置。

未來可以加入 JSON 檔案匯入與匯出功能，或進一步擴充資料庫及帳號登入機制，實現跨裝置雲端同步。

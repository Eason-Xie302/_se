# 習題 2：國立金門大學校務資訊系統 (NQU Campus Portal Lite)

## 一、專案簡介
本專案為模擬「國立金門大學校務行政系統」之核心學生端功能網頁應用程式。針對傳統校務系統介面較為繁複之痛點，重新設計出具備即時衝堂檢測、視覺化功課表與成績 GPA 計算之現代化響應式系統。

## 二、核心功能
1. **線上加退選課程系統**：
   - 支援課程名稱與授課教師關鍵字即時搜尋。
   - **自動衝堂檢查**：加選時自動比對星期與節次，若與已選課程時間重疊會立即攔截並跳出衝堂警告。
   - **學分上限控管**：自動累計已選學分，並儲存於瀏覽器 `LocalStorage` 中。
2. **動態個人功課表**：
   - 根據目前加退選結果，自動生成週一至週五（第 1 至 8 節）之視覺化課表與上課教室資訊。
3. **歷年成績與 GPA 查詢**：
   - 顯示學期平均成績、4.0 制 GPA 換算與畢業學分進度統計。

## 三、啟動方式
直接於瀏覽器開啟 `homework2/index.html`，或使用 VS Code `Live Server` 擴充套件點擊 `Go Live` 即可直接操作。
